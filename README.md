# 🐍 Python — Class Practice & Assignments

Welcome to my **Python learning repository**! 🚀

This repository contains my **Python class practice, assignments, and exercises**, organized topic-wise as I learn and strengthen my programming fundamentals.

Each topic has its own folder containing the code practiced during class and the assignments related to that topic.

---

## 📂 Repository Structure

Each topic is organized like this:

```text
Topic-Name/
│
├── class.py
│   └── Python code and practice completed during class
│
└── assignment.md
    └── Assignments and questions for that particular topic
```

### 📌 Example

```text
01-Introduction to Python/
│
├── class.py
└── assignment.md
```

`class.py` contains the **practice and code completed during class**, while `assignment.md` contains the **assignments and questions for that specific topic**.
